# 🤖 ربات رشد کالکشن | Sanaei Telegram Bot

ربات رشد کالکشن یک ربات تلگرامی برای بررسی و مدیریت اطلاعات مرتبط با سرویس ارائه‌شده است که با پایتون توسعه داده شده و با استفاده از Docker اجرا می‌شود.

## ✨ معرفی پروژه

این پروژه با هدف فراهم کردن یک محیط ساده برای تعامل کاربران با سرویس رشد کالکشن طراحی شده است. ساختار پروژه به‌صورت ماژولار پیاده‌سازی شده تا توسعه، نگهداری و به‌روزرسانی آن آسان‌تر باشد.

## 🚀 امکانات و ویژگی‌ها

- 🤖 پیاده‌سازی ربات تلگرام با استفاده از کتابخانه `aiogram`
- ⚡ توسعه‌یافته با Python 3.12
- 🐳 اجرا و مدیریت سرویس با Docker و Docker Compose
- 🗄️ استفاده از SQLite برای ذخیره‌سازی اطلاعات
- 🔄 قابلیت راه‌اندازی مجدد خودکار کانتینر پس از توقف
- ⚙️ پیکربندی تنظیمات از طریق فایل محیطی `.env`
- 🧩 ساختار ماژولار برای توسعه و نگهداری آسان‌تر
- 🛠️ اسکریپت نصب برای ساده‌تر شدن راه‌اندازی روی سرور Ubuntu

> امکانات دقیق در دسترس کاربران به پیاده‌سازی فعلی ربات و تنظیمات سرور وابسته است.

## 📦 پیش‌نیازها

برای نصب و اجرای پروژه به موارد زیر نیاز دارید:

- سرور یا سیستم دارای Ubuntu یا یک توزیع لینوکس سازگار
- دسترسی به ترمینال و مجوز اجرای دستورات موردنیاز
- Docker
- Docker Compose
- توکن ربات تلگرام از طریق BotFather
- اطلاعات تنظیمات موردنیاز پروژه

## ⚡ نصب سریع

برای دریافت و اجرای اسکریپت نصب، دستور زیر را در ترمینال سرور اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/roshd60mhn/sanaei-telegram-bot/main/install.sh | sudo bash
```

**نکته امنیتی:** پیش از اجرای اسکریپت با دسترسی `sudo`، بهتر است محتوای آن را بررسی کنید.

## ⚙️ تنظیمات

تنظیمات حساس پروژه باید از طریق فایل `.env` مدیریت شوند.

۱. فایل نمونه‌ی `.env.example` را بررسی کنید.

۲. یک فایل `.env` مطابق تنظیمات موردنیاز پروژه بسازید.

۳. توکن ربات و سایر مقادیر ضروری را در آن قرار دهید.

۴. مطمئن شوید فایل `.env` در Git ثبت یا منتشر نشده باشد.

**مهم:** توکن تلگرام، رمزها و سایر اطلاعات محرمانه را در مخزن عمومی قرار ندهید.

## 🐳 اجرای پروژه با Docker

پس از آماده‌سازی تنظیمات، در پوشه‌ی پروژه می‌توانید از دستورات زیر استفاده کنید:

ساخت ایمیج:

```bash
docker compose build bot
```

اجرای سرویس:

```bash
docker compose up -d bot
```

مشاهده‌ی گزارش‌های ربات:

```bash
docker compose logs -f bot
```

بررسی وضعیت سرویس:

```bash
docker compose ps
```

## 🗂️ ساختار پروژه

```text
sanaei-telegram-bot/
├── bot.py
├── config.py
├── database.py
├── sanaei.py
├── utils.py
├── requirements.txt
├── Dockerfile
├── docker-compose.yml
├── install.sh
├── .env.example
├── .gitignore
└── .dockerignore
```

- `bot.py` — نقطه‌ی شروع اجرای ربات
- `config.py` — مدیریت تنظیمات
- `database.py` — عملیات مرتبط با پایگاه داده
- `sanaei.py` — منطق مرتبط با سرویس Sanaei
- `utils.py` — توابع کمکی
- `requirements.txt` — وابستگی‌های پایتون
- `Dockerfile` — دستورالعمل ساخت ایمیج
- `docker-compose.yml` — تنظیمات اجرای سرویس
- `install.sh` — اسکریپت نصب و راه‌اندازی
- `.env.example` — نمونه‌ی تنظیمات محیطی

- دسترسی‌های سرور و پایگاه داده را محدود کنید.
- قبل از اجرای اسکریپت‌های نصب، محتوای آن‌ها را بررسی کنید.
- پیش از به‌روزرسانی پروژه، از داده‌های مهم نسخه‌ی پشتیبان تهیه کنید.
